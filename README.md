# ProperTalk by Pravan

A Streamlit website for **ProperTalk by Pravan**, a personal real-estate media and networking platform.

## Files

- `app.py` — Streamlit website
- `requirements.txt` — Python dependencies

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Community Cloud

1. Create a new public repository on GitHub named `propertalk-by-pravan`.
2. Upload `app.py`, `requirements.txt`, and `README.md` from this folder.
3. Open https://share.streamlit.io/ and sign in with GitHub.
4. Select **Create app**, choose this repository and the `main` branch.
5. Set the main file path to `app.py`, then deploy.

## Before publishing

- Check all links and replace the featured video if you want a different one.
- Add a public business email or contact form when you are ready.
